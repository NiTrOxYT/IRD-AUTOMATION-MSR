IRD Sync Automation — Bundled PuTTY/Plink Portable Tools
=========================================================

These PuTTY/Plink binaries are bundled directly with IRD Sync Automation
and are used by the application's built-in SSH Reverse Tunnel Manager.

- plink.exe : Command-line connection tool for establishing reverse SSH tunnels.
- putty.exe : Graphical SSH client utility.

No installation or administrator privileges required.
These binaries do NOT store passwords, private keys, or credentials.
All credentials remain encrypted on the local machine using Windows DPAPI.
